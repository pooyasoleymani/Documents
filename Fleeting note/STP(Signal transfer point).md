A **Signal Transfer Point** (**STP**) is a node in an **SS7** network that routes signaling messages based on their destination point code in the SS7 network. It works as a router that relays Signalling System No. 7 [[SS7]]messages between _signaling end-points_ [[SEP]]s and other signaling transfer points (**STPs**). Typical **SEPs** include _service switching points_ [[SSP]]s, and _service control points_ (**SCPs**). The **STP** is connected to adjacent **SEPs** and **STPs** via [[signaling links]]. Based on the address fields of the **SS7** messages, the **STP** routes the messages to the appropriate outgoing signaling link.
