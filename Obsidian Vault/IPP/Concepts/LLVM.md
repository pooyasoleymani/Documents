**LLVM** is a set of [[compiler]]and [[toolchain]] technologies that can be used to develop a [frontend](https://en.wikipedia.org/wiki/Compiler#Front_end "Compiler") for any [[programming language]] and a [backend](https://en.wikipedia.org/wiki/Compiler#Back_end "Compiler") for any [instruction set architecture](https://en.wikipedia.org/wiki/Instruction_set_architecture "Instruction set architecture"). LLVM is designed around a [language-independent](https://en.wikipedia.org/wiki/Language-independent_specification "Language-independent specification") [intermediate representation](https://en.wikipedia.org/wiki/Intermediate_representation "Intermediate representation") (IR) that serves as a [portable](https://en.wikipedia.org/wiki/Software_portability "Software portability"), high-level [assembly language](https://en.wikipedia.org/wiki/Assembly_language "Assembly language") that can be [optimized](https://en.wikipedia.org/wiki/Optimizing_compiler "Optimizing compiler") with a variety of transformations over multiple passes. The name _LLVM_ originally stood for _Low Level Virtual Machine._ However, the project has since expanded, and the name is no longer an acronym but an [orphan initialism](https://en.wikipedia.org/wiki/Orphan_initialism)

LLVM is written in [C++](https://en.wikipedia.org/wiki/C%2B%2B "C++") and is designed for [compile-time](https://en.wikipedia.org/wiki/Compile-time "Compile-time"), [link-time](https://en.wikipedia.org/wiki/Linker_\(computing\) "Linker (computing)"), and [runtime](https://en.wikipedia.org/wiki/Runtime_\(program_lifecycle_phase\) "Runtime (program lifecycle phase)") optimization.
