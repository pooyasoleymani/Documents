A **toolchain** is a set of [software development tools](https://en.wikipedia.org/wiki/Software_development_tool "Software development tool") used to [build](https://en.wikipedia.org/wiki/Software_build "Software build") and otherwise [develop](https://en.wikipedia.org/wiki/Software_development "Software development") [software](https://en.wikipedia.org/wiki/Software "Software"). Often, the tools are executed sequentially and form a [pipeline](https://en.wikipedia.org/wiki/Pipeline_\(computing\) "Pipeline (computing)") such that the output of one tool is the input for the next. Sometimes the term is used for a set of related tools that are not necessarily executed sequentially.

A relatively common and simple toolchain consists of the tools to build for a particular [operating system](https://en.wikipedia.org/wiki/Operating_system "Operating system") (OS) and [CPU](https://en.wikipedia.org/wiki/Central_processing_unit "Central processing unit") architecture: a [compiler](https://en.wikipedia.org/wiki/Compiler "Compiler"), a [linker](https://en.wikipedia.org/wiki/Linker_\(computing\) "Linker (computing)"), and a [debugger](https://en.wikipedia.org/wiki/Debugger "Debugger"). With a [cross-compiler](https://en.wikipedia.org/wiki/Cross-compiler "Cross-compiler"), a toolchain can support [cross-platform](https://en.wikipedia.org/wiki/Cross-platform "Cross-platform") development.

For building more complex software systems, many other tools may be in the toolchain. For example, for a [video game](https://en.wikipedia.org/wiki/Video_game "Video game"), the toolchain may include tools for preparing [sound effects](https://en.wikipedia.org/wiki/Sound_effect "Sound effect"), music, [textures](https://en.wikipedia.org/wiki/Texture_\(computer_graphics\) "Texture (computer graphics)"), [3-dimensional models](https://en.wikipedia.org/wiki/3D_model "3D model") and [animations](https://en.wikipedia.org/wiki/Animation "Animation"), and for combining these resources into the finished product.
