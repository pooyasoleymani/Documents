## What is Data ?
*Set* of **storeable** *Objects* or *Entities*.

### Unstructured Data
Data that haven't predefined format.
*Example*: image, text, video, ...

### Semi-Structured Data
Has Structure but not like a table.
*Example*: JSON, XML, HTML, logs.

### Structured Data
Organized like table in *row/column*.
*Example*: SQL, spreadsheets.


## Type of Data
1. Qualitative (Descriptive)
2.  Qualitative (Numeric)
