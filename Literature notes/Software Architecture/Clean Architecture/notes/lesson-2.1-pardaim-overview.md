## Objective

- Overview three paradigms: **structured** ,**object-oriented**, **functional** programming



---

## Structured Programming

Discovered by `Edsger Wybe Dijkstra` in 1968.
Replaced (`goto` statements) those jumps with the more familiar `if/then/else` and `do/while/until` constructs.

> Structured programming imposes discipline on direct transfer of control.




## Object-Oriented Programming

Discover in 1966, by `Ole Johan Dahl` and `Kristen Nygaard`.

> Object-oriented programming imposes discipline on indirect transfer of control.




## Functional Programming

> Functional programming imposes discipline upon assignment.
