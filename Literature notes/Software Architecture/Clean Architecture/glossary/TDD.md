## Definition

**Test-driven development** (**TDD**) is a way to write [source code](https://en.wikipedia.org/wiki/Source_code "Source code") that involves writing an [automated](https://en.wikipedia.org/wiki/Test_automation "Test automation") [unit-level](https://en.wikipedia.org/wiki/Unit_testing "Unit testing") [test case](https://en.wikipedia.org/wiki/Test_case_\(software\) "Test case (software)") that fails, then writing just enough code to make the test pass, then [refactoring](https://en.wikipedia.org/wiki/Refactoring "Refactoring") both the test code and the production code, then repeating with another new test case.
