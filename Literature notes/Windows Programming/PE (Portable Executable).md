# اول باید PE را واقعاً بفهمی

PE مخفف Portable Executable است. این قالب استاندارد فایل‌های اجرایی ویندوز است و ساختار فایل‌هایی مثل موارد زیر را تعریف می‌کند:

- `.exe` — فایل اجرایی
- `.dll` — کتابخانه پویا
- `.sys` — درایور ویندوز

برای مثال، وقتی ویندوز یک فایل EXE را اجرا می‌کند، Loader باید ساختار PE را بخواند تا متوجه شود بخش‌های مختلف فایل کجا هستند، کد از کجا شروع می‌شود و چه کتابخانه‌هایی باید بارگذاری شوند.
