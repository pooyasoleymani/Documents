## scikit-build-core Bridge CMake and Python 

scikit-build-core implement [[PEP 517]] as build backend that read `pyproject.toml`
to drive `CMake` eliminating fragile custom `setup.py` wrappers previously need in projects like *Numpy*.

as a backend, it interact with frontend (**pip**, **build**) while translating Python build requests into **CMake** invocations.
this solves [[dependency hell]] in mixed languages projects by enforcing [[dependency isolation]] at build layer.

See also: [[CMake]], [[pyproject.toml]], [[pip]], [[PEP 517 backend protocol]]
